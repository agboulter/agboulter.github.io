# agboulter.github.io
COMP208 Assessment Task
- Online teaching portfolio containing information about me, a resume, work samples, teaching philosophy and a contact page.
- Portfolio is designed for potential employees to view various details about myself, my degree and my experiences.
- Each page provides different information, including examples of projects that I have completed, and unit plans that I have developed.

Colour Palette: Various tones of green, with white and black text varying for readability. The main setion colours are:
- #7AA586
- #55D55

Accessibility Notes: 
- The home page contains a navigation bar accessing all pages, and an additional link to the About Me, Resume and Teaching philosophy pages.
- The about me page contains a navigation bar accessing all pages, and an additional link to the Work Samples page. A photo montage has been included in this page, use the arrows at the bottom of the section to scroll through the images
- The resume page contains a navigation bar accessing all pages. There is a button at the bottom to download a PDF version of the resume.
- The Work samples page contains a navigation bar accessing all pages.
- The teaching philosophy page contains a navigation bar accessing all pages. There are three images in this page, each acting as a button to download a PDF version of the specified file.
- The contact me page contains a navigation bar accessing all pages. There is a contact for that may be filled out, with a form validation to ensure all fields are completed.
- The website is accessible on all forms of devices.
